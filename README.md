# SecureSpam – Blockchain-Based Spam Detection

## About the Project
SecureSpam is a cybersecurity project designed to identify suspicious messages, phishing links and possible scam attempts. It aims to help individuals and organizations recognize online threats while protecting their personal information.

## Problem Statement
Spam and phishing messages can trick people into sharing passwords, OTPs and other confidential information. This creates privacy and security risks for individuals, businesses, hospitals and educational institutions.

## Our Solution
SecureSpam aims to:
- Detect suspicious messages and phishing indicators.
- Display a risk level with clear explanations.
- Identify and mask sensitive information where possible.
- Use blockchain to support tamper-evident security-event records.
- Avoid storing original private messages on the blockchain.

## Technologies
- HTML, CSS and JavaScript
- Python and Flask
- SHA-256 hashing
- Solidity and a local blockchain development network
